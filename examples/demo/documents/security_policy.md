# 企业安全规范

## 1. 访问控制

### 1.1 身份认证
- 所有系统必须使用统一认证（SSO）
- 密码强度：最少12位，包含大小写字母+数字+特殊字符
- 密码过期：90天
- 连续5次失败锁定30分钟

### 1.2 权限管理
- 基于 RBAC 的权限模型
- 最小权限原则（Principle of Least Privilege）
- 权限定期审计（季度）
- 账号禁用后立即回收权限

### 1.3 API 安全
- 所有 API 必须经过认证
- 敏感操作需要二次确认
- API 调用记录完整审计日志
- 传输层使用 TLS 1.3

## 2. 数据安全

### 2.1 数据分类

| 级别 | 定义 | 示例 | 存储要求 |
|------|------|------|---------|
| L1 | 公开信息 | 产品文档 | 无特殊要求 |
| L2 | 内部信息 | 设计文档 | 访问控制 |
| L3 | 敏感信息 | 客户数据 | 加密存储 |
| L4 | 机密信息 | 密钥证书 | 硬件加密 |

### 2.2 数据加密
- 传输加密：TLS 1.3
- 存储加密：AES-256
- 密钥管理：定期轮转（90天）
- 数据库：透明数据加密（TDE）

### 2.3 数据备份
- 关键数据：每日全量 + 每小时增量
- 备份保留：30天
- 灾难恢复：异地备份
- 备份加密：AES-256

## 3. 审计日志

### 3.1 审计范围
- 所有认证事件（登录/登出/失败）
- 所有权限变更
- 所有敏感数据访问
- 所有配置变更
- 所有API调用（>=L3）

### 3.2 日志格式
```json
{
  "timestamp": "2026-08-18T10:00:00Z",
  "actor": "user_id",
  "action": "document.delete",
  "resource": "doc_123",
  "tenant": "tenant_456",
  "result": "success|denied|error",
  "ip": "10.0.1.100",
  "user_agent": "Mozilla/5.0..."
}
```

### 3.3 日志存储
- 存储周期：至少1年
- 不可篡改：Write-Once-Read-Many (WORM)
- 实时告警：异常行为检测
- 定期审计：日志完整性校验

## 4. 漏洞管理

### 4.1 漏洞扫描
- 代码扫描：每次提交（SAST）
- 依赖扫描：每日（SCA）
- 容器扫描：每次构建
- 渗透测试：每季度

### 4.2 漏洞处理 SLA

| 严重程度 | 修复时间 | 示例 |
|---------|---------|------|
| Critical | 24小时 | RCE、SQL注入 |
| High | 7天 | XSS、CSRF |
| Medium | 30天 | 信息泄露 |
| Low | 90天 | 最佳实践 |

## 5. 合规要求

### 5.1 等保2.0
- 安全通信网络
- 安全区域边界
- 安全计算环境
- 安全管理中心

### 5.2 GDPR 合规
- 数据最小化收集
- 用户数据可删除
- 数据处理记录
- 跨境传输合规
